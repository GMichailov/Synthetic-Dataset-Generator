# Synthetic-Dataset-Generator

This is a project I created that can quickly generate massive amounts of pretraining and SFT data locally by distilling from a local LLM rather than relying on downloading massive amounts of uncleaned data from the internet and then formatting it. It automatically distills high-quality data from:
  - mathematics
  - physics
  - biology
  - chemistry
  - computer science
  - engineering
  - medicine
  - history
  - economics
  - philosophy
  - literature
  - geography

In order to build fun AI projects locally.

Additionally, there are scripts here for generating SFT data from an LLM again in the format that you would like.
